PROMPT PARA GENERACIÓN DE DIAPOSITIVAS: MARKETAWS ARCHITECTURE

Actúa como un Arquitecto de Soluciones Cloud Senior. Necesito crear una presentación técnica impactante sobre el proyecto "MarketAWS: Marketplace Serverless de Alta Disponibilidad". La presentación debe cubrir los siguientes puntos clave basados en la infraestructura real implementada:

1. Título y Visión General: "MarketAWS - Transformando el E-commerce con Arquitectura Serverless y Despliegue Progresivo en AWS".

2. Capa de Entrega y Frontend:
   - Uso de Application Load Balancer (ALB) para distribución de tráfico.
   - Implementación de Canary Deployment (70/30) mediante Nginx como Reverse Proxy en instancias EC2.
   - Explicación de cómo se gestiona el tráfico Main vs Canary sin downtime.

3. Ciclo de Vida del Producto (Vendedores):
   - Almacenamiento escalable en S3.
   - Validación automatizada mediante Event-Driven Architecture: S3 Trigger -> Lambda -> AWS Rekognition.
   - Filtrado de contenido explícito y gestión de objetos rechazados.

4. Procesamiento de Órdenes y Resiliencia:
   - Flujo asíncrono: API Gateway -> Lambda -> SQS.
   - Importancia del desacoplamiento para manejar picos de tráfico.
   - Gestión de errores mediante Dead Letter Queues (DLQ) y monitoreo con EventBridge cada 5 minutos.

5. Patrón Fan-out con SNS:
   - El corazón de la mensajería: Una sola publicación distribuida a múltiples suscriptores.
   - Suscriptores: SQS de Pagos, SQS de Notificaciones al Vendedor, Lambda de Inventario y Notificaciones por Email.
   - Uso de Filter Policies para asegurar que cada servicio reciba solo lo que necesita.

6. Persistencia y Seguridad:
   - RDS MySQL en subredes privadas (VPC) para máxima seguridad.
   - Capas de Lambda (Layers) para gestión eficiente de dependencias (mysql2, SDK).
   - IAM Roles con principio de mínimo privilegio.

7. Conclusión: Ventajas de esta arquitectura en escalabilidad, costos (Pay-as-you-go) y mantenibilidad.

ESTILO VISUAL SUGERIDO: Moderno, tecnológico, con diagramas de flujo y colores que representen los servicios de AWS (Naranja, Azul, Púrpura). Usa un tono profesional pero innovador.
